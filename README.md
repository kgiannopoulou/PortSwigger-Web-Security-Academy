# My Cybersecurity Learning Journey

I'm interested in learning cybersecurity, and along the way I came across [PortSwigger's Web Security Academy](https://portswigger.net/web-security) — a free, hands-on set of labs covering real web application vulnerabilities. I decided to work through it and document what I learn as I go, so I'm taking you along on the journey with me.

This repo is a day-by-day log of the labs I complete: what the vulnerability actually is, how I found and exploited it, and what the underlying lesson is. It's as much for my own future reference as it is for anyone else just getting started.
